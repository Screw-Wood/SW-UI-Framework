# Bugs: tests

Bugs in the test suite itself under `src/tests/`, rather than in the code under test: a test that is wrong, flaky, non-deterministic, depends on the environment, or a gap where a behaviour the [release gate](../../foundational/Architecture.md#4-testing-gate-for-release) requires has no test. A bug the tests *caught* is filed in the area where it occurs, not here.

New bugs go here as `NNNN-short-description.md`. See [how to file a bug](../README.md#how-to-file-one).
