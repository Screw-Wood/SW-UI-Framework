# Bugs: accessibility

Bugs that happen in `src/framework/accessibility/` or in how widgets expose themselves to assistive technology: wrong or missing role, name or state, broken keyboard-only operation, and failures found in the screen-reader review ([Stage 7](../../Implementation/STAGES.md#stage-7--screen-reader-review)).

New bugs go here as `NNNN-short-description.md`. See [how to file a bug](../README.md#how-to-file-one).
